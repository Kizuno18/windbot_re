# Overview

WindBot dominated mid-2010s Tibia classic automation with a polished Qt UI,
Lua scripting, cavebot/targeting/healing suites, and a forum-tied license model.
Version numbering historically tracked CipSoft client versions (e.g. `windbot1076-2.6.2.exe`);
later 2.8.x builds advertise multi-client ranges such as `10.00-47`, with a
separate 2.9.x line for Client 11.

This study anchors on **2.6.2 ↔ Tibia 10.76 ↔ TFS 1.1** for a coherent
protocol/client stack, while retaining **2.8.30** as the newest publicly listed
classic-10 installer for provenance.
